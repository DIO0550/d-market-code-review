# Review Defensive Code

## Description

仕様が要求していない「念のため」のフォールバックや防御的コード（不要なtry-catch、とりあえずの既定値、黙示のフォールバック）をレビューし、削除または仕様化を提案するコマンドです。

## Prompt Template

`defensive-code-reviewer`エージェントを使用して、防御的コード・フォールバックをレビューしてください。

以下のタスクを実行してください：

1. **スキルの参照ファイルを使用してレビュー基準を取得する**

   - `code-review-skill:defensive-code-review` を取得し、レビュー基準を確認

2. **防御的コード・フォールバックを分析する**

   - 対象ファイルまたはディレクトリのコードを読み込み
   - try-catch、`??`/`||` による既定値、null チェック、フォールバック分岐を特定
   - 各分岐を評価基準に照らして評価

3. **問題のある箇所を分類する**

   - 例外の握りつぶし（catch して null/既定値で続行）
   - 型・バリデーションで保証済みの値への「とりあえず」の防御
   - 失敗時に黙って別実装へ切り替えるフォールバック
   - 仕様フォールバックの3点セット不足（コメント+出典 / 観測手段 / テスト）

4. **改善提案を提供する**
   - 削除して失敗を伝播させる箇所と、仕様化して3点セットを揃える箇所を区別
   - エラー処理をシステム境界へ集約する提案

## Notes

- エラー処理は仕様が要求する場所（システム境界、エントリポイント、ハンドラ）にだけ書く
- システム境界での一元的なエラー処理は指摘しない
- 3点セットの揃った仕様フォールバックは指摘しない
- レビュー結果は日本語で提供
